# Cyber Security Guidelines

## 1. Common Cyber Security Threats in Remote Work

Remote work introduces several security risks because employees may work from different locations, networks, and devices.

Some common threats include:

* **Phishing attacks** – fake emails, messages, or websites designed to steal credentials or sensitive information.
* **Malware** – malicious software that can damage devices or give attackers unauthorized access.
* **Weak or reused passwords** – if one account is compromised, reused passwords can put multiple accounts at risk.
* **Unsecured Wi-Fi networks** – public or poorly secured networks can expose sensitive information.
* **Social engineering** – attackers may manipulate people into revealing confidential information or performing unsafe actions.
* **Malicious links and attachments** – clicking suspicious links or opening unexpected files can lead to malware infections or credential theft.
* **Unattended devices** – leaving a computer unlocked can allow another person to access company information.

---

## 2. Best Practices for Keeping Devices and Accounts Secure

To protect company and user data, I should:

* Use strong and unique passwords for different accounts.
* Enable two-factor authentication (2FA) whenever it is available.
* Keep the operating system, browser, and applications updated.
* Use a password manager instead of storing passwords in insecure places.
* Lock my computer whenever I leave it unattended.
* Use screen lock and biometric authentication where available.
* Avoid connecting to unknown or unsecured networks when handling sensitive information.
* Be careful with links, attachments, and unexpected messages.
* Only install software from trusted sources.
* Avoid sharing passwords or authentication codes with other people.

---

## 3. Why Locking My Computer Is Important

Locking my computer when I step away from my desk prevents unauthorized people from accessing my accounts, files, messages, or company information.

Even if I am only away for a few minutes, an unlocked device can provide direct access to sensitive information.

For this reason, I should treat locking my computer as a routine habit rather than something I remember only when working with sensitive data.

I will use automatic screen locking as an additional layer of protection.

---

## 4. Handling Phishing Attempts and Suspicious Links

If I receive a suspicious email or message, I should not immediately click links, open attachments, or provide credentials.

I would:

1. Check the sender and message carefully.
2. Look for unusual requests, spelling mistakes, urgency, or suspicious links.
3. Avoid entering credentials through links received in unexpected messages.
4. Verify the request through a trusted communication channel if necessary.
5. Report the suspicious message according to the company's security procedures.
6. Delete or quarantine the message after it has been properly reported.

If I accidentally click a suspicious link or provide credentials, I would report the incident immediately rather than trying to hide the mistake.

---

## 5. Strong Passwords and Password Managers

A strong password should be long, unique, and difficult to guess. Passwords should not be reused across important accounts.

Using a different password for every account limits the damage if one password is compromised.

A password manager is useful because it can:

* Generate strong and unique passwords.
* Store passwords securely.
* Reduce the need to remember many passwords.
* Make password reuse less likely.
* Help identify weak or reused passwords.

Instead of keeping passwords in plain text files or notes, I should use a trusted password manager.

---

## 6. Why 2FA Is Important

Two-factor authentication adds an additional layer of protection beyond a password.

If an attacker obtains my password, 2FA can still prevent them from accessing the account if they cannot provide the second authentication factor.

I should enable 2FA on work accounts whenever it is available, especially for accounts that provide access to company systems, source code, communication platforms, or sensitive information.

# 9. Securing My Passwords and Accounts

I will take the following steps to improve the security of my accounts:

1. Review my important work-related accounts.
2. Replace any reused or weak passwords with strong, unique passwords.
3. Store passwords using a trusted password manager.
4. Enable 2FA wherever supported.
5. Review account recovery options.
6. Check for unfamiliar login sessions or devices.
7. Never share passwords or 2FA codes with anyone.

---

# 10. What I Would Do If I Suspected a Security Breach

If I noticed suspicious activity, such as an unfamiliar login, unexpected password reset, or other unusual account activity, I would act quickly.

My first steps would be:

1. Report the incident to the appropriate Focus Bear contact or security channel.
2. Change the affected password from a trusted device.
3. Revoke suspicious sessions or access tokens if possible.
4. Enable or reset 2FA if necessary.
5. Check whether other accounts using the same credentials could be affected.
6. Preserve relevant evidence, such as suspicious emails, login notifications, or screenshots.
7. Follow any additional instructions provided by the company.

I would not attempt to investigate or fix a potentially serious security incident on my own if doing so could destroy evidence or make the situation worse.

---

# 11. My Personal Rule for Secure Behaviour

My rule is:

> **Stop, verify, then act.**

Before clicking a suspicious link, sharing information, downloading a file, or approving an unexpected authentication request, I will stop and verify that the action is legitimate.

I want secure behaviour to become automatic rather than something I think about only after a security problem occurs.

By consistently using strong unique passwords, 2FA, automatic device locking, careful handling of suspicious messages, and secure password storage, I can reduce the risk of accidentally exposing company or user data.
